# 게임 제작 에셋 폴더

이 폴더에는 게임에 실제로 표시하거나 재생할 그림, 소리, 글꼴만 넣습니다.

## 제작 기준

- 배경: `1920×1080`, 16:9 비율, WebP 또는 PNG
- 캐릭터·소품·UI: 투명 배경 WebP 또는 PNG
- 배경음·효과음: MP3와 OGG를 함께 준비하면 브라우저 호환성이 좋습니다.
- 파일명: 영문 소문자, 숫자, 하이픈만 사용하고 공백은 넣지 않습니다.

## 폴더

- `images/backgrounds`: 로비와 각 스테이지 배경
- `images/characters`: 플레이어와 등장인물
- `images/props`: 택시, 컵, 냄비 같은 소품
- `images/ui`: 아이콘과 게임 화면 장식
- `audio/bgm`: 배경음악
- `audio/sfx`: 효과음
- `fonts`: 웹폰트

새 파일을 넣은 뒤 `js/asset-manager.js`에 경로와 게임용 이름을 한 번 등록합니다. 로비와 각 스테이지의 배경 슬롯은 미리 연결되어 있어, 주석으로 준비된 경로를 활성화하면 기존 임시 배경 대신 새 배경이 표시됩니다. 경로는 GitHub Pages의 저장소 하위 주소에서도 작동하도록 `./assets/...` 형식을 유지합니다.
